# greenhouse_monitor

 🌿 Greenhouse Monitor

> 🎉 Ласкаво просимо до репозиторію мобільного додатку **Greenhouse Monitor**!

Це кросплатформенний додаток, створений з ❤️ на Flutter, для моніторингу стану теплиці 🌱 у реальному часі.

 📱 Основні можливості:
- Відображення температури, вологості, CO₂ та освітленості
- Історія спостережень з графіками
- Локальні та Telegram-сповіщення при перевищенні порогів
- Підтримка кількох теплиць на одного користувача
- Ручне додавання та редагування теплиць
